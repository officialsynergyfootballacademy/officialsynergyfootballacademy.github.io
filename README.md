# Synergy Football Academy Website

A responsive static website built with HTML, CSS and JavaScript.

## Files
- index.html — main website
- css/style.css — styling and responsive layout
- js/script.js — mobile navigation and current year
- images/logo.jpg — academy logo

## Run locally
